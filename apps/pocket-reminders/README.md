# あとでやる

自分用リマインダーアプリ。iPhone向けのレスポンシブ画面、追加・編集・完了・延期・削除、表示フィルター、R2での永続保存。Sitesの所有者限定アクセスで保護する。

初回アクセス時に「楽天銀行・ゆうちょのスマホATM設定」（2026年10月10日19時、日本時間）を保存する。削除後は復活しない。タスクはGitHubではなく私有のR2に保存される。

## 通知

画面が開いているときの時刻通知のみ。バックグラウンドのプッシュ配信は未実装。各タスクからVALARM付きICSを出力できる。カレンダーへの取り込みと通知設定はユーザーが行う。取り込み済みの予定はアプリの編集や削除と自動同期しない。

## 実行

`bash scripts/build.sh`
`node scripts/validate-artifact.mjs`
`node --test tests/worker.test.mjs`

Cloudflare Workerの`BUCKET`にR2バケットをバインドする。Sitesの非公開ホスティングを前提とする。外部で公開する場合はAPIの認証・認可を追加する。`.openai/hosting.json`はSites固有のため別プロジェクトへ複製する際はIDを引き継がない。
